# Rule: no personal data and no third-party artwork

- **No e-mail addresses** anywhere in the repository, in files or in commits. Commits use the GitHub noreply
  address. Security reports go through GitHub private vulnerability reporting.
- No secrets, tokens, home paths or machine names in the repository.
- **No names or logos of other products as artwork.** The icon is an original design (`assets/icon.svg`). Plain-text
  mentions of Vibe Island and Rex are fine, together with the disclaimer in `README.md`.
