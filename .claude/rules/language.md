# Rule: the working language of this repository is English

- **Everything in this repository is in English**: code (names of variables, functions, classes, files and log
  lines), commit messages, branch names, pull request titles and descriptions, issues and documentation
  (`README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CLAUDE.md`).
- The app has no user-facing texts other than the log lines, which are English too.
- Chat with the maintainer may be in any language; what ends up in the repository is English.
